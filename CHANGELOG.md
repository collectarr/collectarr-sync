# Changelog

## Unreleased

### Features
- Images users load for list values, such as Custom Label images, sync between devices.

### Fixes
- Pick list values keep their sort name, hidden state and a borrower's contact details when they sync.

## 0.5.0 - 2026-11-07

### Docs
- The README describes self-hosting and links the current documentation, without emoji or screenshot placeholders.

### Features
- Each signed-in account keeps its own library, and the first device to sign in moves the shared library into its account.

### CI & Build
- Release notes contain only a bulleted summary and a flat list of every commit.
- Releases file the Unreleased changelog entries under the new version and set the package version automatically.
- Releases no longer carry a banner image.

## 0.4.0 - 2026-10-31

### Features
- Synchronize Comics catalog snapshots and personal grading, key significance and collection data without losing fields.

### CI & Build
- Release notes list every merged pull request, direct commit and closed issue, and record new release summaries in the repository.

### Docs
- Present releases with a banner showing each release's headline, highlights, feature and fix counts and project stats at publication, plus editorial summaries, contributor credits and automatic change lists.
